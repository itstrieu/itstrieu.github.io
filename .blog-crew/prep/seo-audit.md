### Critical OG image issue

The `image` front matter on posts is just a filename (e.g., `image: welcome.jpg`). The post layout uses it as:
```html
<img src="{{ site.github.url }}/assets/img/{{ page.image }}">
```

But `jekyll-seo-tag` doesn't know about this prefix. It will output the `og:image` as-is (just the filename) or try to resolve it against `url` + `baseurl`. Social media crawlers need an absolute URL like `https://itstrieu.github.io/assets/img/welcome.jpg`.

**Fix:** Change image values in front matter to include the path:
```yaml
image: /assets/img/welcome.jpg
```
Or configure a default in `_config.yml`:
```yaml
defaults:
  - scope:
      path: ""
      type: "posts"
    values:
      image: /assets/img/default-og.png
```

### baseurl double-slash issue

`baseurl: "/"` in `_config.yml` will cause `jekyll-seo-tag` to generate canonical URLs like `https://itstrieu.github.io//why-i-call-myself-an-ai-systems-builder`. The trailing slash on baseurl concatenates with the leading slash on the path. This should be:

```yaml
baseurl: ""
```

## 4. Missing Infrastructure

### 4a. No default OG image

Six of seven posts have images, but one does not (`why-i-call-myself-an-ai-systems-builder`). Any post shared without an image will have no visual on social platforms — a significant engagement loss.

**Needed:** A site-level default OG image (e.g., 1200x630px) and a `defaults` block in `_config.yml`.

### 4b. No Twitter Card configuration

Zero Twitter/X card metadata is being generated. The `jekyll-seo-tag` plugin supports it natively with:

```yaml
twitter:
  username: itstrieu  # or whatever the handle is
  card: summary_large_image
```

### 4c. No `robots.txt`

Search engines will crawl without it, but a `robots.txt` pointing to the sitemap helps:

```
User-agent: *
Allow: /
Sitemap: https://itstrieu.github.io/sitemap.xml
```

### 4d. No `lang` attribute on `<html>` tag

`_layouts/default.html` has `<html>` with no `lang` attribute. This is an accessibility and SEO signal.

### 4e. No structured author data

`jekyll-seo-tag` can generate richer JSON-LD if the author is configured as an object:

```yaml
author:
  name: "Kathy Trieu"
  url: "https://itstrieu.github.io/about"
```

And `social.links` in `_config.yml` would populate `sameAs` in the Person schema:

```yaml
social:
  name: Kathy Trieu
  links:
    - https://github.com/itstrieu
    - https://www.linkedin.com/in/itstrieu
```

### 4f. No meta description on non-post pages

The About page (`pages/about.md`) has no `description` in its front matter. `jekyll-seo-tag` will fall back to auto-excerpt, which may be truncated awkwardly.

### 4g. Alt text missing on images

In `_layouts/post.html`, the featured image has no `alt` attribute:
```html
<img src="{{ site.github.url }}/assets/img/{{ page.image }}">
```

Should be:
```html
<img src="{{ site.github.url }}/assets/img/{{ page.image }}" alt="{{ page.title }}">
```

### 4h. Google Analytics not active

`google-ID` in `settings.yml` is empty. The old Universal Analytics (`analytics.js`) script is also deprecated — Google shut it down in 2024. If analytics are wanted, this needs to be replaced with GA4 or removed entirely.
